# Innocencia Mkhatswa – Portfolio

My personal portfolio website, built with plain **HTML, CSS and JavaScript** (no frameworks).

🔗 Live site: `https://innocencia-lindokuhle-mkhatswa.github.io/portfolio/` *(after GitHub Pages is turned on)*

## Features

- Moving-dots background on the home section
- About section with quick facts, plus an Experience & Education timeline
- Light / dark mode that remembers your choice
- Programming language cards (Java, JavaScript, Python, PHP, SQL, HTML5) with logos
- Six internship projects (Auspify Technologies) with cover images, a level filter (Easy / Medium / Advanced) and a details pop-up
- Contact form that sends messages to my email (FormSubmit)
- Fully responsive: computer, tablet and phone
- Respects visitors who turn off animations on their device

## Folder structure

```

├── index.html          ← the content (structure)
├── cv.pdf              ← my CV (add this)
├── css/
│   └── style.css       ← the look (colours, layout, animations)
├── js/
│   └── script.js       ← the behaviour (interactions)
└── images/

```

## How to edit

| I want to change… | Go to |
|---|---|
| Text, sections, links | `index.html` |
| Colours | top of `css/style.css` (`:root`) |
| Project pop-up details | top of `js/script.js` (`projects` list) |

**Contact form:** after uploading, send one test message from the live site, then click "Activate Form" in the email FormSubmit sends you (check Spam). Messages are only delivered after that.

Search for `EDIT ME` to find the places that still need my details.
